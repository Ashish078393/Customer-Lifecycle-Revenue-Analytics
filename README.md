# E-Commerce Customer Lifecycle & Revenue Analytics

## Project Overview
An end-to-end SQL analytics project analyzing customer buying patterns, product performance, and revenue trends.

## Directory Structure
- `schema/schema.sql`: Table creation DDL.
- `data/`: Sample CSV datasets for categories, products, customers, orders, and order items.
- `queries/`: SQL scripts for RFM segmentation, revenue growth, product ranking, and cohort analysis.
